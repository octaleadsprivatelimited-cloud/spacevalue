# Space Value

Real estate channel partner website built with React, TanStack Start, Vite and Tailwind CSS.

## Development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
node .output/server/index.mjs
```

Agent registration details live in `src/components/site/data.ts`. The original certificate and its image are served from `public/`. Project registration IDs are separate from the agent registration.
